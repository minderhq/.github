# Getting help

Thanks for using Minder! Here's the fastest path to what you need.

## Documentation first

Most questions are answered in the docs — **<https://minderhq.github.io/docs/>** —
covering the product, self-hosting, the CLI, and the plugin-authoring guide.

## Questions & ideas → Discussions

For usage questions, ideas, and show-and-tell, use **GitHub Discussions** on the
relevant repository (enabled on
[plugin-sdk](https://github.com/minderhq/plugin-sdk/discussions),
[plugins](https://github.com/minderhq/plugins/discussions),
[client](https://github.com/minderhq/client/discussions),
[cli](https://github.com/minderhq/cli/discussions),
[deploy](https://github.com/minderhq/deploy/discussions), and
[docs](https://github.com/minderhq/docs/discussions)). Prefer Discussions over
issues for anything that isn't a confirmed bug or a concrete feature request.

## Bugs & feature requests → Issues

Found a reproducible bug, or have a concrete proposal? Open an issue **in the
repository it affects**, using the provided templates.

## Building a plugin

Start from the [plugin-sdk](https://github.com/minderhq/plugin-sdk) and the
[plugin-template](https://github.com/minderhq/plugin-template) — plugins are
manifest-based with no arbitrary code execution.

## Security

Do **not** open a public issue for security problems — follow the
[Security Policy](SECURITY.md) (private vulnerability reporting).
